Question Schema Documentation

Supported Question Types
MCQ Multiple Choice Questions

Required fields:

  • id - Unique identifier (letters, numbers, hyphens, underscores)
  • type - Must be "mcq"
  • question_text - The question text
  • options - Array of answer options (minimum 2)
  • correct_answer - ID of the correct option

Optional fields:

  • difficulty - "easy", "medium", or "hard"
  • tags - Array of tags
  • hints - Array of hint strings
  • explanation - Solution explanation
NUMERIC Numeric Questions

Required fields:

  • id - Unique identifier
  • type - Must be "numeric"
  • question_text - The question text
  • answer - The correct numeric answer

Optional fields:

  • tolerance - Acceptable tolerance (default: 0)
  • units - Units for the answer (e.g., "meters", "kg")
  • difficulty, tags, hints, explanation
CSV Format

CSV files should have the following headers:

id,type,question_text,difficulty,tags,hints,explanation,options,correct_answer,answer,tolerance,units

Note: Use semicolons (;) to separate multiple values in tags, hints, and options. For options, use the format: id1:text1;id2:text2
